# Changelog

## 1.0.0 — 2026-07-25

- Created the DoneToday React PWA.
- Added one-task-per-day workflow.
- Added 10, 25, and 50 minute focus sessions.
- Added pause, restart, and reset controls.
- Added completion history and streak calculation.
- Added local-only persistence and data reset.
- Added iPhone standalone metadata, safe-area layout, manifest, and service worker.
- Added responsive styling, reduced-motion support, and keyboard focus states.
- Added date and streak unit tests.
- Deployed production release to Vercel.
